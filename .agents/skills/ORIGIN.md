# Origem das skills Neon

Os arquivos dos diretórios desta pasta foram instalados de [neondatabase/agent-skills](https://github.com/neondatabase/agent-skills).
A origem é distribuída sob a licença Apache 2.0, reproduzida em [LICENSE](LICENSE).
O arquivo `skills-lock.json` na raiz registra a origem de cada skill instalada.
Essas skills são instruções de desenvolvimento e não fazem parte da execução do HydroTech.
